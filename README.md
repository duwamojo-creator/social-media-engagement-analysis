# social-media-engagement-analysis
Power BI dashboard analyzing social media engagement and sentiment patterns using likes, comments, and shares.
Overview

This project uses Microsoft Power BI to analyze social media engagement and sentiment patterns. The dashboard examines how likes, comments, and shares vary across positive, neutral, and negative sentiment categories.

Tools
Microsoft Power BI
DAX
Microsoft Excel
Data Visualization
Analysis

The dashboard explores:

Sentiment distribution
Average likes by sentiment
Average comments by sentiment
Average shares by sentiment
Relationships between social media engagement and sentiment score
